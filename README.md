# 栖伴 / Qiban Companion

iOS companion runtime with user-selected local character packages and a configurable chat endpoint. Includes opt-in on-device speech recognition, sound classification, rear main-camera preview and bounded visual touch springs. With video enabled, sending a text or voice turn (or pressing the look-at-camera button) sends one current JPEG to the selected vision endpoint, or to chat when no independent vision service is enabled. Images are not stored in chat backups. Speech recognition defaults to local processing. If the user enables an independent ASR endpoint, microphone recordings of at most 30 seconds are uploaded to that endpoint for transcription. Recognized text or sound labels may be sent to the chat endpoint. Camera-based gaze estimation has been removed; local touch gaze remains.

Independent vision, web search, TTS and ASR profiles each have their own URL, protocol and device-only keychain credential. The default chat key is never borrowed. Supported adapters: Chat Completions image input, DeepSeek Search/TTS/ASR, and OpenAI-compatible speech/transcription. Search only runs for turns where the user enables its composer toggle; the query is limited to 128 characters and returned links are visible in history. External observations and search summaries are treated as reference data. Optional remote TTS sends only cleaned speech; local voices remain available when it is disabled. Cancelled remote speech cannot overwrite a newer playback generation. Profile settings are backed up without credentials.

Mood metadata and unified source-action intents can start movements with actual speech playback. A reply missing body metadata or the selected Japanese speech can trigger at most one bounded follow-up request to the selected endpoint; images and the full history are not resent. Japanese supplementation keeps the existing Chinese display and any explicit body decision. Character placement can be edited independently of a local scene.

This repository contains runtime code and synthetic tests only. No game models, voices, textures, extracted shaders, account credentials, research files or private development history are distributed. Import only resources you are authorized to use. This project is not affiliated with any game publisher.

Build using XcodeGen and Xcode, or the manually dispatched standard macOS Actions workflow. The three compatibility secrets configure bundle identity, private storage namespace and keychain service for existing installations; use your own identifiers for a new installation. Build results are unsigned and saved to a draft release.

The real-device camera, microphone, latency and touch appearance require device validation. This is not a full soft-body simulator or a copy of a commercial application's call service.
