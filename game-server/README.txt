栖伴牌桌 · 朋友房间服务 1.0

一、启动
解压整个 ZIP，双击根目录的“启动牌桌服务.cmd”，保持窗口运行。
包内附官方 Node.js 24.22.1 Windows x64 运行时，不需要 npm 或另外安装模块。
启动后，访问密钥会生成在 game-server/.room-server-key。用记事本打开，复制给朋友。
控制台列出的 http://地址:17890 是可用候选地址。只在本次需要的网络上允许防火墙入站连接。

二、同一 Wi-Fi 或局域网
在 App 首页点“游戏”，填写服务地址与服务访问密钥。
一个人点“创建房间”，其他人填写得到的 6 位游戏房间号，再点“加入房间”。
客人点“准备好了”，房主点“开始牌局”；空位可用电脑补齐。
房主可在开局前的单机座位设置中选好电脑角色；开始朋友牌局时沿用对应空位的设置。
每人独立选择自己的昵称与形象。联机分享的是当前选中的压缩图片和显示名。

三、网易 UU 云联机
UU 提供虚拟局域网，仍然需要一台电脑运行这个牌桌房间服务。
电脑与手机先在 UU 中加入同一个“通用联机房”，将运行服务的电脑虚拟 IP 填入 App：
http://电脑在UU里的虚拟IP:17890
然后在 App 里创建／加入游戏房间。
UU 房间号与本游戏的 6 位房间号不是同一个号码。
用户给出的加速器 APK 仅做了静态清单检查，没有安装、运行或接入其私有接口。
不同平台／系统的 VPN 转发策略是否支持本 App，需要在真实设备上确认。
若无法访问虚拟地址，可改用自己部署的 HTTPS 牌桌服务。

四、自建远程服务与 MCP
服务没有第三方 Node 依赖，可把 game-server 和 games 两个目录一起部署到自己的服务器。
默认直接运行 node game-server/server.mjs 只监听 127.0.0.1:17890。
对外监听时设置 QIBAN_GAME_HOST 与 QIBAN_GAME_KEY，或使用 --lan --key-file 密钥文件。
可用环境变量：QIBAN_GAME_PORT、QIBAN_GAME_HOST、QIBAN_GAME_KEY。
反向代理 /api 与 /mcp 到服务，保留 JSON POST；推荐使用自己的 HTTPS 域名。
浏览器入口为同一服务的 /；若使用域名，QIBAN_GAME_PUBLIC_HOSTS 填入允许的域名，用逗号分隔。
QIBAN_ALLOWED_ORIGINS 可按需指定额外允许的完整浏览器来源，默认不允许其他网页访问。
App 使用原生网络桥连接服务器，不需要开放任意跨域来源。

MCP 地址：https://自己的域名/mcp
认证头：Authorization: Bearer 服务访问密钥
工具：qiban_create_room、qiban_join_room、qiban_room_state、qiban_room_action。
每个工具返回本座位状态；座位 token 用于重连和操作，请保留在自己的设备上。
普通 MCP 服务器需要挂载这份房间服务才具有游戏功能。

五、连接与存档
普通断线：在原设备返回游戏首页，点“重连上次房间”。不要换设备重新占座。
在进行中的牌局点“离开房间”会把该座位交给电脑，自己的原凭证失效。
关闭 App 或暂时回陪伴不会主动放弃联机座位；长时间断线的人类座位仍等待本人操作。
所有人主动离开后房间结束；房间最长闲置 12 小时自动清理。
服务当前使用内存保存房间，关闭／重启服务会结束牌局，没有数据库恢复。
单机则在手机自动存档，可以从游戏首页继续。

六、资源与范围
P5 和尘白立绘按 .qcards 单独在 App 导入，服务器包不含商业游戏资源。
可自定义角色名、立绘与独立头像；没有图片的内置角色也能开局。
没有沿用原 Windows 包作者的服务器，没有捆绑原游戏可执行文件或 DLL。
本版重建了 3/4 人 Tycoon 牌规与自己的界面，未移植原版完整音乐、配音、过场及演出系统。
提示音可关闭，牌桌不会启动聊天 TTS。角色外观不会改变规则或获得未定义技能。
